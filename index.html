Formula Cheat Sheet

The exact tools you need for this test.

IMAGINARY UNIT
√−1 = i · i² = −1
√−a = i√a (then simplify the radical). √−16 = 4i, √−12 = 2i√3.
MULTIPLY √− RADICALS
Pull out i FIRST
√−a · √−b = i√a · i√b = i²√(ab) = −√(ab). Never combine negatives directly!
POWERS OF i ⭐
Divide the exponent by 4, use the remainder
R1 → i · R2 → −1 · R3 → −i · R0 → 1.
a + bi OPERATIONS
Add/Subtract: combine real & imaginary. Multiply: FOIL
After FOIL, replace i² with −1 and combine.
COMPLEX CONJUGATE
a + bi ↔ a − bi
(a + bi)(a − bi) = a² + b² — always a real number.
QUADRATIC FORMULA
x = (−b ± √(b² − 4ac)) / 2a
Set the equation = 0 first. A negative under the radical → complex answers.
DISCRIMINANT b² − 4ac ⭐
tells you the number & type of solutions
< 0 → 2 complex (no x-ints) · = 0 → 1 real · > 0 perfect square → 2 rational · > 0 not perfect square → 2 irrational.
